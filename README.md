# Arduino Controlled Humidifier

## Overview

This project was designed for our CPE301.1001 embedded systems class and was designed using the classes rubric in mind. This includes interaticing with the arduinos registers for GPIO, ADC, and Serial communication. The serial, pinmode, and analog read functions were not used in our code. We also used a Arduino Mega 2560, but an Arduino Uno should work with code modification.\

This project was created with the idea of gardening and growing plantlife in dryier climates like the state of Nevada. If a user wants to grow tropical plants in a small enviroment, this project will allow the user to set a desired humidity level and the system will keep the humidity within 5% of the users set value. This allows for proper water levels for the plant life while allowing the user to save and conserve water reasorces.
